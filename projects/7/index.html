Specification

A secondary-school physics textbook designed to make dense scientific content legible and navigable. The layout system uses a strict 12-column grid — generous enough for diagrams, tight enough for precision.

Format A4 Portrait
Grid 12-Column
Chapters 18 Units
Medium Illustrator

Layout System

01 Chapter opener uses a full-bleed diagram panel — ink on cream, no photographic image. Forces occupy the visual hierarchy above words.
02 Body text runs at 10/16pt Palatino. The classical serif carries authority without weight. Equations are typeset in a contrasting mono to signal code-like precision.
03 Marginal callouts use the Stone palette — reduced opacity, reduced size — so they scaffold understanding without competing with the primary flow.

Process

01
Content Map
All 18 chapters mapped to a hierarchy of concept, example, exercise, and extension. The grid system follows from this.
02
Diagram System
Each diagram follows a strict visual grammar: ink weight, arrow style, label placement — consistent from chapter one to eighteen.
03
Print Proof
Final spreads exported at 300 dpi, proofed on physical stock. Ink density adjusted per chapter to maintain consistent read-depth across print runs.
